# Going Up!

A small, charming lift-management game for phones. Tap a floor to send the lift; passengers hop
on and off by themselves. Deliver them before their patience runs out.

```
npm install
npm run dev
```

Open the printed URL. To try it on a phone, use the "Network" address while on the same Wi-Fi.

Desktop keys: `G`/`0`–`4` jump to a floor, `↑`/`↓` step the lift.

Scoring: 10 coins per delivery, up to +15 for a quick trip, and +5 × n for the n-th extra passenger
dropped at the same stop. Five walkouts end the shift.
